# Introduction

The Operational Context Graph (OCG) is a central shared data store for a data center. It holds the complete operational picture of the infrastructure: what exists, what is happening, what has been done, and what is understood.

The OCG stores and serves data. It does not analyze, decide, or act. Consuming systems read from it and apply their own reasoning.
